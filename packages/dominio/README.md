# @cuadreapp/dominio

Única fuente de verdad para las reglas de validación R1–R12 y los cálculos de negocio (existencia, autonomía, gal/hora) — ver `docs/ESPEC_App_Cuadre_Lubryco.md` §7 y §9.

TypeScript puro, sin dependencias de navegador ni de un framework de servidor específico, para que `apps/pwa` y `apps/api` importen exactamente la misma lógica. Una regla, un lugar.

Se implementa en la **Etapa 1** del roadmap. Este directorio es un placeholder de workspace hasta entonces.

# 04 · Catálogo de tipos de página

Doce tipos cubren 115 páginas. **No existe un decimotercero sin agregarlo aquí primero.**

**Por qué se cataloga:** diagramar página por página produce 115 decisiones independientes y, a los tres meses, 115 páginas que no se parecen entre sí. Con doce tipos, produce doce decisiones y un documento que se lee igual en cualquier punto.

**«Máximo de conceptos» es el límite duro.** Un concepto es algo que la persona tiene que entender y recordar: un paso no es un concepto, pero «la tanda debe estar en cero» sí lo es. Cuando una página supera su límite, se parte (`PR-02`).

---

## `T-01` · Hero _(portada)_

|                         |                                                                                  |
| ----------------------- | -------------------------------------------------------------------------------- |
| **Objetivo**            | Que alguien reconozca su planta y su trabajo antes de leer una palabra           |
| **Contenido**           | Fotografía a sangre, título en lenguaje de trabajo, audiencia, tiempo de lectura |
| **Máximo de conceptos** | **1** — a quién le sirve esto                                                    |
| **Imágenes**            | 1, a sangre, fotografía real de campo                                            |
| **Texto máximo**        | 40 palabras                                                                      |
| **Usos**                | 7                                                                                |

El título nunca nombra el producto: «Cargar combustible con CuadreApp», no «Manual de usuario de la PWA».

## `T-02` · Apertura de capítulo

|                         |                                                       |
| ----------------------- | ----------------------------------------------------- |
| **Objetivo**            | Situar a la persona en el momento del mundo real      |
| **Contenido**           | Momento, objetivo, qué está ocurriendo                |
| **Máximo de conceptos** | **1** — cuándo ocurre esto                            |
| **Imágenes**            | 0 o 1; si hay, fotografía de campo, **nunca captura** |
| **Texto máximo**        | 90 palabras                                           |
| **Usos**                | 28                                                    |

Un capítulo empieza en la planta, no en el teléfono.

## `T-03` · Paso a paso

|                         |                                            |
| ----------------------- | ------------------------------------------ |
| **Objetivo**            | Que la persona ejecute mientras lee        |
| **Contenido**           | Pasos, prohibiciones, captura con llamados |
| **Máximo de conceptos** | **2**                                      |
| **Imágenes**            | 1 captura + hasta 2 zooms                  |
| **Texto máximo**        | 160 palabras                               |
| **Usos**                | 34                                         |

**El tipo más usado del sistema.** La imagen va después de los pasos (`PR-04`, excepción).

## `T-04` · Comparativa

|                         |                                        |
| ----------------------- | -------------------------------------- |
| **Objetivo**            | Enseñar un error en dos segundos       |
| **Contenido**           | 2 o 3 imágenes en fila + una frase     |
| **Máximo de conceptos** | **1** — el error que se está enseñando |
| **Imágenes**            | 2 o 3, **nunca 4**                     |
| **Texto máximo**        | 60 palabras, pies incluidos            |
| **Usos**                | 9                                      |

Lo incorrecto primero (`PR-09`). El mensaje dice qué hacer, no qué se ve.

## `T-05` · Zoom

|                         |                                                        |
| ----------------------- | ------------------------------------------------------ |
| **Objetivo**            | Ampliar la zona donde ocurre la acción                 |
| **Contenido**           | Captura completa pequeña + recorte grande + un callout |
| **Máximo de conceptos** | **1**                                                  |
| **Imágenes**            | 2 — la misma imagen a dos escalas                      |
| **Texto máximo**        | 35 palabras                                            |
| **Usos**                | 51, casi siempre incrustado en `T-03`                  |

## `T-06` · Decisión

|                         |                                                    |
| ----------------------- | -------------------------------------------------- |
| **Objetivo**            | Llevar a un supervisor de «veo esto» a «hago esto» |
| **Contenido**           | La jerarquía B completa                            |
| **Máximo de conceptos** | **3**                                              |
| **Imágenes**            | 1 captura + hasta 2 zooms                          |
| **Texto máximo**        | 220 palabras                                       |
| **Usos**                | 14                                                 |

Es el tipo con más conceptos permitidos porque un supervisor lee sentado (`PR-10` no aplica igual).

## `T-07` · Proceso administrativo

|                         |                                                               |
| ----------------------- | ------------------------------------------------------------- |
| **Objetivo**            | Ejecutar un proceso de principio a fin sin volver a preguntar |
| **Contenido**           | La jerarquía C completa                                       |
| **Máximo de conceptos** | **3**                                                         |
| **Imágenes**            | hasta 4 capturas                                              |
| **Texto máximo**        | 400 palabras                                                  |
| **Usos**                | 7                                                             |

**El único tipo que puede ocupar dos páginas seguidas** (`PR-08`). Partirlo a la mitad obliga a pasar la hoja con las manos en el teclado.

## `T-08` · Dashboard

|                         |                                                                    |
| ----------------------- | ------------------------------------------------------------------ |
| **Objetivo**            | Enseñar a leer una vista completa antes de operar sobre ella       |
| **Contenido**           | Una captura grande con 3 o 4 llamados numerados + qué mira primero |
| **Máximo de conceptos** | **2**                                                              |
| **Imágenes**            | 1 captura a media página + hasta 4 llamados                        |
| **Texto máximo**        | 120 palabras                                                       |
| **Usos**                | 4                                                                  |

**Se usa una sola vez por manual de supervisor**, al abrir. Repetir la vista completa en cada decisión gasta media página enseñando lo que ya se sabe.

## `T-09` · Checklist

|                         |                                |
| ----------------------- | ------------------------------ |
| **Objetivo**            | Verificar, no enseñar          |
| **Contenido**           | Casillas agrupadas por momento |
| **Máximo de conceptos** | **0** — no introduce ninguno   |
| **Imágenes**            | 0                              |
| **Texto máximo**        | 120 palabras                   |
| **Usos**                | 7                              |

**Cero imágenes y cero conceptos nuevos, a propósito.** Quien usa un checklist ya sabe hacer el trabajo.

## `T-10` · Troubleshooting

|                         |                                              |
| ----------------------- | -------------------------------------------- |
| **Objetivo**            | Encontrar la propia frase y saber qué hacer  |
| **Contenido**           | Tabla: lo que dice → qué hacer ahora → ficha |
| **Máximo de conceptos** | **0** — solo redirige a lo ya enseñado       |
| **Imágenes**            | 0                                            |
| **Texto máximo**        | 250 palabras                                 |
| **Usos**                | 7                                            |

La columna «lo que dice» manda: es por donde se busca. **Una página de problemas que introduce un concepto nuevo está mal ubicada** — ese concepto debía estar en su capítulo.

## `T-11` · Preguntas frecuentes

|                         |                                       |
| ----------------------- | ------------------------------------- |
| **Objetivo**            | Responder la duda tal como se formula |
| **Contenido**           | Pregunta en negrita + respuesta corta |
| **Máximo de conceptos** | **0**                                 |
| **Imágenes**            | 0                                     |
| **Texto máximo**        | 300 palabras                          |
| **Usos**                | 7                                     |

Las preguntas se escanean; las respuestas se leen solo cuando una coincide.

## `T-12` · Fin de proceso _(cierre)_

|                         |                                                     |
| ----------------------- | --------------------------------------------------- |
| **Objetivo**            | Dejar la sensación de que esto se domina en un rato |
| **Contenido**           | Tabla de tiempos: la primera vez / en rutina        |
| **Máximo de conceptos** | **1** — cuánto va a costar cuando ya sepa           |
| **Imágenes**            | 0 o 1                                               |
| **Texto máximo**        | 80 palabras                                         |
| **Usos**                | 7                                                   |

La columna «en rutina» es la que importa: es la promesa de que el esfuerzo baja.

---

## `T-13` · Guía rápida _(tipo especial)_

|                         |                                                     |
| ----------------------- | --------------------------------------------------- |
| **Objetivo**            | Reemplazar el manual una vez que la persona ya sabe |
| **Contenido**           | La jerarquía D completa                             |
| **Máximo de conceptos** | **2**                                               |
| **Imágenes**            | 0 o 1 diagrama esquemático                          |
| **Texto máximo**        | 200 palabras                                        |
| **Usos**                | 4                                                   |

**Una cara de una hoja carta. Laminada.** Si no cabe, sobra contenido — **nunca se reduce el cuerpo de texto para que quepa** (`PR-02`, `PR-10`).

Es el único tipo que se juzga por lo que se le quitó, no por lo que tiene.

# Plantillas de página

Una plantilla no es un layout. Un layout dice dónde va cada cosa en una página concreta; una plantilla dice **qué tipo de página es, qué cabe y qué no**.

**Por qué importa la diferencia:** con 115 páginas y siete manuales, diagramar página por página produce 115 decisiones. Con diez plantillas, produce diez.

**El presupuesto de texto es un límite, no una meta.** Una plantilla que se desborda no se comprime: se parte en dos páginas.

---

## `PL-01` · Portada

|                  |                                                                                  |
| ---------------- | -------------------------------------------------------------------------------- |
| **Objetivo**     | Que alguien reconozca su planta y su trabajo antes de leer una palabra           |
| **Contenido**    | Fotografía a sangre, título en lenguaje de trabajo, audiencia, tiempo de lectura |
| **Imágenes**     | **1** — a sangre, fotografía real de campo                                       |
| **Texto máximo** | 40 palabras                                                                      |
| **Jerarquía**    | Fotografía → título → audiencia → resto                                          |
| **Usos**         | 7 (una por manual)                                                               |

El título nunca nombra el producto: «Cargar combustible con CuadreApp», no «Manual de usuario de la PWA».

---

## `PL-02` · Apertura de capítulo

|                  |                                                             |
| ---------------- | ----------------------------------------------------------- |
| **Objetivo**     | Situar a la persona en el momento del mundo real            |
| **Contenido**    | Bloque de momento (`CMP-11`), objetivo, qué está ocurriendo |
| **Imágenes**     | 0 o 1 — si hay, fotografía de campo, nunca captura          |
| **Texto máximo** | 90 palabras                                                 |
| **Jerarquía**    | Número y nombre del capítulo → momento → objetivo           |
| **Usos**         | 28                                                          |

**Nunca abre con una captura de pantalla.** El capítulo empieza en la planta, no en el teléfono.

---

## `PL-03` · Paso a paso

|                  |                                                               |
| ---------------- | ------------------------------------------------------------- |
| **Objetivo**     | Que la persona ejecute mientras lee                           |
| **Contenido**    | Pasos numerados, «qué nunca debe hacer», captura con llamados |
| **Imágenes**     | 1 captura + hasta 2 zooms                                     |
| **Texto máximo** | 160 palabras                                                  |
| **Jerarquía**    | Pasos → prohibiciones → imagen                                |
| **Usos**         | 34                                                            |

**Es la plantilla más usada del kit.** La imagen va **después** de los pasos: quien está ejecutando lee la acción primero y confirma con la imagen, no al revés.

---

## `PL-04` · Comparativa

|                  |                                         |
| ---------------- | --------------------------------------- |
| **Objetivo**     | Enseñar un error en dos segundos        |
| **Contenido**    | Dos o tres imágenes en fila + una frase |
| **Imágenes**     | 2 o 3 — **nunca 4**                     |
| **Texto máximo** | 60 palabras, incluidos los pies         |
| **Jerarquía**    | Imágenes → mensaje principal → pies     |
| **Usos**         | 9                                       |

Lo incorrecto va primero. El mensaje principal no describe las imágenes: dice qué hacer.

---

## `PL-05` · Zoom

|                  |                                                               |
| ---------------- | ------------------------------------------------------------- |
| **Objetivo**     | Ampliar la zona donde ocurre la acción                        |
| **Contenido**    | Captura completa pequeña + recorte grande + un callout        |
| **Imágenes**     | 2 — la misma imagen a dos escalas                             |
| **Texto máximo** | 35 palabras                                                   |
| **Jerarquía**    | Recorte grande → callout → contexto pequeño                   |
| **Usos**         | 51 (normalmente incrustada en `PL-03`, no como página propia) |

---

## `PL-06` · Decisión

|                  |                                                                                        |
| ---------------- | -------------------------------------------------------------------------------------- |
| **Objetivo**     | Llevar a un supervisor de «veo esto» a «hago esto»                                     |
| **Contenido**    | Si ve esto → qué significa → qué revisar → qué decidir → a quién llamar → qué no hacer |
| **Imágenes**     | 1 captura + hasta 2 zooms                                                              |
| **Texto máximo** | 220 palabras                                                                           |
| **Jerarquía**    | Síntoma → significado → decisión                                                       |
| **Usos**         | 14                                                                                     |

La sección «qué no hacer» **nunca se omite**: en las decisiones de supervisor, el daño casi siempre viene de actuar de más, no de menos.

---

## `PL-07` · Proceso completo

|                  |                                                                                   |
| ---------------- | --------------------------------------------------------------------------------- |
| **Objetivo**     | Ejecutar un proceso administrativo de principio a fin sin volver a preguntar      |
| **Contenido**    | Empieza cuando → prerrequisitos → pasos → cómo sabe que salió bien → qué no hacer |
| **Imágenes**     | Hasta 4 capturas                                                                  |
| **Texto máximo** | 400 palabras (puede ocupar dos páginas)                                           |
| **Jerarquía**    | Prerrequisitos → pasos → verificación                                             |
| **Usos**         | 7                                                                                 |

Es la única plantilla que puede ocupar dos páginas seguidas, porque partir un proceso administrativo a la mitad obliga a pasar la hoja con las manos en el teclado.

---

## `PL-08` · Checklist

|                  |                                |
| ---------------- | ------------------------------ |
| **Objetivo**     | Verificar, no enseñar          |
| **Contenido**    | Casillas agrupadas por momento |
| **Imágenes**     | 0                              |
| **Texto máximo** | 120 palabras                   |
| **Jerarquía**    | Grupos → casillas              |
| **Usos**         | 7                              |

**Cero imágenes, a propósito.** Quien usa un checklist ya sabe hacer el trabajo.

---

## `PL-09` · Guía rápida

|                  |                                                               |
| ---------------- | ------------------------------------------------------------- |
| **Objetivo**     | Reemplazar el manual una vez que la persona ya sabe           |
| **Contenido**    | Pasos numerados, los tres sellos, tres errores, prohibiciones |
| **Imágenes**     | 0 o 1 diagrama esquemático                                    |
| **Texto máximo** | 200 palabras                                                  |
| **Jerarquía**    | Los pasos ocupan la mitad superior                            |
| **Usos**         | 4                                                             |

**Una cara de una hoja carta. Laminada.** Si no cabe, sobra contenido — nunca se reduce el cuerpo de texto para que quepa: en una planta, a pleno sol, un cuerpo pequeño no se lee.

---

## `PL-10` · Problemas

|                  |                                                       |
| ---------------- | ----------------------------------------------------- |
| **Objetivo**     | Encontrar la propia frase y saber qué hacer           |
| **Contenido**    | Tabla: lo que dice → qué hacer ahora → ficha          |
| **Imágenes**     | 0                                                     |
| **Texto máximo** | 250 palabras                                          |
| **Jerarquía**    | La columna «lo que dice» manda: es por donde se busca |
| **Usos**         | 7                                                     |

---

## `PL-11` · Preguntas frecuentes

|                  |                                                                            |
| ---------------- | -------------------------------------------------------------------------- |
| **Objetivo**     | Responder la duda tal como se formula                                      |
| **Contenido**    | Pregunta en negrita + respuesta corta                                      |
| **Imágenes**     | 0                                                                          |
| **Texto máximo** | 300 palabras                                                               |
| **Jerarquía**    | Las preguntas se escanean; las respuestas se leen solo cuando una coincide |
| **Usos**         | 7                                                                          |

---

## `PL-12` · Cierre de manual

|                  |                                                     |
| ---------------- | --------------------------------------------------- |
| **Objetivo**     | Dejar la sensación de que esto se domina en un rato |
| **Contenido**    | Tabla de tiempos (primera vez / en rutina)          |
| **Imágenes**     | 0 o 1                                               |
| **Texto máximo** | 80 palabras                                         |
| **Usos**         | 7                                                   |

La columna «en rutina» es la que importa: es la promesa de que el esfuerzo baja.

---

## Cómo se combinan

```
MANUAL DE OPERADOR (16 páginas)
  PL-01 portada
  PL-02 + PL-03 × 7 capítulos
  PL-04 comparativas          (donde aplique)
  PL-10 problemas
  PL-08 checklist
  PL-11 preguntas frecuentes
  PL-12 cierre

MANUAL DE SUPERVISOR (18 páginas)
  PL-01 → PL-06 × 7 → PL-04 → PL-08 → PL-11 → PL-12

MANUAL DE ADMINISTRADOR (22 páginas)
  PL-01 → PL-07 × 7 → PL-10 → PL-08 → PL-11 → PL-12

GUÍA RÁPIDA (1 página)
  PL-09
```

## Resumen

| Plantilla           | Usos | Imágenes    | Texto máximo |
| ------------------- | ---- | ----------- | ------------ |
| `PL-01` Portada     | 7    | 1           | 40           |
| `PL-02` Apertura    | 28   | 0–1         | 90           |
| `PL-03` Paso a paso | 34   | 1 + 2 zooms | 160          |
| `PL-04` Comparativa | 9    | 2–3         | 60           |
| `PL-05` Zoom        | 51   | 2           | 35           |
| `PL-06` Decisión    | 14   | 1 + 2 zooms | 220          |
| `PL-07` Proceso     | 7    | hasta 4     | 400          |
| `PL-08` Checklist   | 7    | 0           | 120          |
| `PL-09` Guía rápida | 4    | 0–1         | 200          |
| `PL-10` Problemas   | 7    | 0           | 250          |
| `PL-11` Preguntas   | 7    | 0           | 300          |
| `PL-12` Cierre      | 7    | 0–1         | 80           |

**Doce plantillas cubren 115 páginas.** Tres de ellas —`PL-02`, `PL-03` y `PL-05`— cargan con el 65 % del trabajo: si esas tres quedan bien resueltas, el resto del kit se diagrama casi solo.

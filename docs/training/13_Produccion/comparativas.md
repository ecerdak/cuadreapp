# Biblioteca de comparativas

Una comparativa es dos imágenes juntas y una sola frase. Es el recurso más eficiente del kit: enseña en dos segundos lo que un párrafo no logra en treinta.

**Regla de construcción:** la imagen incorrecta va **primera**, la correcta **después**. En ese orden el lector reconoce su propio error antes de ver la solución, y la solución se le queda. Al revés, ve la solución, asiente y no aprende nada.

**Regla de contenido:** el mensaje principal nunca describe las imágenes. Dice qué hacer.

| **Formato**           | Dos píldoras, una al lado de la otra                                                       |

## `K-08` · Lo que un descuadre significa y lo que no

|                       |                                                                                  |
| --------------------- | -------------------------------------------------------------------------------- |
| **Objetivo**          | Evitar que un supervisor acuse a alguien con la evidencia equivocada             |
| **Imágenes**          | Ninguna: dos columnas de texto                                                   |
| **Formato**           | Tabla de dos columnas — «Lo que la gente asume» / «Lo que casi siempre es»       |
| **Mensaje principal** | **«Un salto de totalizador no es combustible perdido: el medidor ya lo contó.»** |
| **Dónde**             | `SUP-MD` decisión 6 · `QG-SUP` · storyboard `SUP-MD` escena 8                    |

| Lo que la gente asume       | Lo que casi siempre es                               |
| --------------------------- | ---------------------------------------------------- |
| Alguien se robó combustible | Un dígito mal copiado                                |
| Falta producto en el tanque | Una carga que se hizo sin abrir la aplicación        |
| El sistema falló            | El sistema detectó exactamente lo que debía detectar |

**Es la única comparativa dirigida a un supervisor, y es la más importante del kit** — no por frecuencia, sino por consecuencia: es la que evita acusar a una persona sin pruebas.

# Guías rápidas

**Una página. Nada más.** Estas guías no resumen el manual: lo reemplazan una vez que la persona ya sabe.

## Para qué sirven

El manual se lee una vez, cuando alguien entra. La guía rápida se cuelga junto al surtidor y se mira durante meses. Son productos distintos y se escriben distinto.

## Reglas de escritura

1. **Una hoja carta, por una sola cara.** Si no cabe, sobra algo.
2. **Cero explicaciones.** El manual explica; la guía rápida ordena.
3. **Verbo en imperativo al empezar cada línea.** «Ponga la tanda en cero», no «la tanda debe estar en cero».
4. **Máximo 12 líneas de acción.** Más que eso no se lee de un vistazo.
5. **Un solo bloque de errores**, con las tres cosas que realmente pasan.
6. **Sin nombres de pantallas.** Quien la mira está viendo la pantalla.

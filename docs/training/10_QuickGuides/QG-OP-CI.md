# REGISTRAR UN CARROTANQUE · GUÍA RÁPIDA

**Operador · control de inventario**

---

## USTED ESCRIBE DOS NÚMEROS. NADA MÁS.

```
┌────────────────────────────────────────┐
│  CON CUÁNTO LLEGÓ        →  lo escribe │
│  DESPACHADO POR LUBRYCO  →  lo escribe │
│  ──────────────────────────────────    │
│  TOTAL AL SALIR          →  LO CALCULA │
│                             LA APP     │
└────────────────────────────────────────┘
```

**No busque dónde escribir el total. No existe, y es a propósito.**

---

## CADA CARGA — 6 PASOS

**1.** Abra la aplicación **desde el ícono**.

**2.** Toque **Cargar combustible** y elija el vehículo. **Mire la placa.**

**3.** Tome la foto del carrotanque **completo, con placa**.

**4.** Escriba **con cuántos galones llegó**. Si llegó vacío: **0,0**.

**5.** Despache. Al terminar: foto de nuevo y escriba **solo lo que echó Lubryco**.

**6.** Guarde y mire el sello.

## SI PASA ESTO

**No aparece el carrotanque** → escriba menos letras. Si no aparece, avise. **No use otro.**

**No sé con cuánto llegó** → pregúntele al conductor. **No lo calcule usted.**

**No hay señal** → trabaje normal. Sube sola. **NUNCA repita una carga.**
